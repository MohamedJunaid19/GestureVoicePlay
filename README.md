# GestureVoicePlay – Real-Time Gesture & Voice Controlled Gaming

GestureVoicePlay is an interactive gaming control system that enables users to play PC games using real-time hand gestures and voice commands instead of traditional input devices. Built using Python, OpenCV, and NLP techniques, the project combines computer vision and speech processing to create a seamless, touch-free gaming experience.

The system captures live webcam input to detect and track hand gestures for controlling in-game actions such as movement, shooting, jumping, and navigation. Simultaneously, voice commands are processed using Natural Language Processing (NLP) to execute additional controls and game functions in real time.

## Key Features

* 🎮 Real-time game control using hand gestures
* 🖐️ Gesture recognition with OpenCV and computer vision
* 🎙️ Voice command integration using NLP and speech recognition
* ⚡ Low-latency input processing for smooth gameplay
* 🧠 Customizable gesture and voice mappings
* 💻 Hands-free and accessible gaming interaction

## Tech Stack

* **Programming Language:** Python
* **Computer Vision:** OpenCV
* **Speech Recognition & NLP:** SpeechRecognition, NLP libraries
* **Other Tools:** NumPy, MediaPipe (if used), PyAutoGUI (if used)

## Applications

* Accessible gaming for users with physical limitations
* Touch-free human-computer interaction
* Smart entertainment systems
* Experimental AI-based game controllers

This project demonstrates the integration of Computer Vision and Natural Language Processing to create an immersive and intelligent gaming control experience.
